# 📸 Instagram Profile Card

A simple **Instagram Profile Card** built using **HTML5 and CSS3**.

## 🌐 Live Demo

[View Live Demo](https://basim-27.github.io/instagram-profile-card/)

## 🛠️ Technologies Used

* HTML5
* CSS3

## ✨ Features

* Instagram-style profile card
* Profile picture
* Followers, following and posts stats
* Follow Me button
* Hover effect
* Dark theme
* Responsive viewport setup
